    Theory

    Core concepts and every component

    Learn this part once. The same pieces appear in every practical.

    Servlet

    A Java class running on a web or application server. It receives HTTP requests and produces dynamic responses. It extends HttpServlet (package javax.servlet.http). Only one servlet object exists and many threads use it, so instance variables are shared between users. Keep per-user data in the session, not in a field.

    Servlet life cycle

    Load + instantiate→init() once→service() per request → doGet / doPost→destroy() once

    Servlet viva

    GET versus POST?

    GET sends data in the URL (visible, limited size, can be bookmarked, only for reading) and calls doGet(). POST sends data in the request body (hidden, no size limit, for login, registration, upload) and calls doPost().

    forward() versus include() versus sendRedirect()?

    forward passes control to another resource on the server, the URL does not change, same request object. include adds the other resource's output into the current response and control comes back. sendRedirect tells the browser to make a new request, the URL changes, request data is lost, and it can go to another website.

    Why is HTTP called stateless?

    Each request is independent and the server does not remember earlier ones. Cookies and sessions are used to remember the user.

    @WebServlet versus web.xml?

    @WebServlet("/X") (Servlet 3.0+) maps the URL by annotation. The older way is <servlet> and <servlet-mapping> in web.xml. Both cannot map the same name.

    ServletConfig versus ServletContext?

    ServletConfig is one per servlet (its init parameters). ServletContext is one per web application and is shared by all servlets (getServletContext()).

    PrintWriter versus ServletOutputStream?

    PrintWriter writes characters (text, HTML). ServletOutputStream writes bytes (images, files). You cannot use both in the same response.

    Tomcat versus GlassFish?

    Tomcat is a web container only (servlet, JSP). GlassFish is a full Java EE server (servlet, JSP, EJB, JMS, JPA, JTA). That is why the EJB practicals run on GlassFish.

    JDBC

    JDBC (Java Database Connectivity) is the java.sql API for connecting Java programs to relational databases and running SQL. MySQL Connector/J is a Type 4 (thin, pure Java) driver.

    Class or methodMeaning
    DriverManagerManages drivers and creates connections
    ConnectionOne session with the database: close(), setAutoCommit(), commit(), rollback()
    StatementRuns a fixed SQL string
    PreparedStatementPrecompiled SQL with ? placeholders. setString(i,v), setInt(i,v), setDouble(i,v). Index starts at 1
    CallableStatementCalls stored procedures
    ResultSetRows returned by a SELECT. next() moves to the next row; getString(col), getInt(col) read columns
    executeQuery()Returns a ResultSet
    executeUpdate()Returns an int, the number of rows affected
    execute()Returns boolean; used when the statement type is unknown
    Statement versus PreparedStatement?

    PreparedStatement is precompiled (faster when repeated), uses ? parameters and prevents SQL injection. Statement joins strings and is unsafe for user input.

    What is SQL injection?

    An attacker types SQL text such as ' OR '1'='1 in an input box to change the query. Prepared statements treat input only as data.

    Why Class.forName()?

    It loads the driver class so it registers with DriverManager. From JDBC 4 it loads automatically, but we keep it for safety.

    JDBC URL format?

    jdbc:mysql://host:port/database, for example jdbc:mysql://localhost:3306/enterprisedb.

    Why DBUtil and try-with-resources?

    DBUtil writes the connection code once, so a password change is made in one place. Try-with-resources closes the connection, statement and result set automatically, even after an exception.

    JSP

    JSP (JavaServer Pages) is a text page with HTML plus Java code. The container converts it into a servlet. JSP is best for presentation (view); servlets are best for logic (controller).

    Action tag<jsp:forward>, <jsp:include>, <jsp:useBean>Built-in XML-style tags

    JSP versus Servlet?

    A servlet is Java code with HTML inside println. A JSP is HTML with Java inside and is converted into a servlet automatically. JSP is easier for designers.

    include directive versus jsp:include?

    The directive merges the file at translation time (static). The action includes at request time (dynamic).

    Why avoid scriptlets in real projects?

    They mix logic with HTML. EL and JSTL are preferred. The syllabus programs use scriptlets to demonstrate JDBC.

    pageContext versus page?

    pageContext gives access to all scopes and other implicit objects. page is just this.

    application versus session?

    application is shared by all users. session is for one user.

    EJB

    EJB (Enterprise JavaBeans) is the server-side component architecture of Java EE for business logic. The EJB container gives services automatically: transactions, security, concurrency, bean pooling, dependency injection and remote access.

    TypeAnnotationStateUse in this guide
    Stateless session bean@StatelessNo client state; instances come from a poolCurrency converter, room booking, marks entry
    Stateful session bean@StatefulKeeps data for one client across callsShopping cart
    Singleton session bean@SingletonOne instance for the whole applicationHit counter, visitor statistics
    Message-driven bean@MessageDrivenNo client view; reacts to JMS messagesVisitor statistics
    AnnotationMeaning
    @EJBInjects a reference to an EJB
    @ResourceInjects a container resource (queue, connection factory, DataSource)
    @Local, @RemoteDeclare the interface type. Local = same JVM, fast. Remote = other JVM
    @RemoveCalling this method of a stateful bean ends its life
    @Lock(READ/WRITE)Concurrency for singleton methods. WRITE = exclusive, READ = shared
    @StartupCreates the singleton at application start
    @PostConstruct, @PreDestroyLife-cycle callbacks
    @TransactionAttributeTransaction behaviour (default REQUIRED)
    @ActivationConfigPropertyMDB settings such as queue name and type

    JNDI (Java Naming and Directory Interface) is the naming service where the container registers beans and resources. new InitialContext().lookup(name) finds them. Portable names look like java:module/BeanName, java:app/..., java:global/....

    EJB versus JavaBean?

    A JavaBean is an ordinary class with getters and setters. An EJB is a managed server-side component with container services such as transactions, pooling and security.

    Stateless versus stateful?

    A stateless bean keeps no client data, so any instance can serve any request (scalable). A stateful bean keeps data for one specific client.

    Why can EJBs run inside a WAR?

    From EJB 3.1 beans can be packaged in a web application. No separate EJB jar or EAR is needed.

    What is a business method?

    Any public method of the bean exposed to clients, for example convert(). In NetBeans: Alt+Insert > Add Business Method.

    JMS

    TermMeaning
    Point-to-point (Queue)Each message is consumed by one receiver
    Publish/subscribe (Topic)The message goes to all subscribers
    ConnectionFactoryCreates connections to the JMS provider
    Connection, SessionLink to the provider; single-threaded context for sending and receiving
    MessageProducerSends messages to a destination
    TextMessageA message holding a String
    MessageListener.onMessage()Called when a message arrives (implemented by the MDB)

    JMS gives asynchronous, loosely coupled communication. The sender does not wait for the receiver.

    ORM, JPA and persistence

    ORM (Object Relational Mapping) maps Java classes to tables, objects to rows and fields to columns, so you work with objects instead of SQL. JPA (Java Persistence API) is the Java EE specification (interfaces) for ORM. Hibernate is one implementation (provider). In ORMLab, Hibernate is the JPA provider (HibernatePersistenceProvider).

    AnnotationMeaning
    @EntityClass is mapped to a table
    @Table(name=...)Sets the table name (default = class name)
    @IdPrimary key field
    @GeneratedValue(strategy=IDENTITY)Database generates the key (MySQL auto increment)
    @Column(length=500)Column settings (name, length, nullable, unique)
    @Temporal(TIMESTAMP)Maps java.util.Date to date and time
    Object or methodMeaning
    Persistence.createEntityManagerFactory("EnterprisePU")Builds the factory for the persistence unit. It is heavy, so create it once (static in JPAUtil)
    EntityManagerPerforms database operations. Created from the factory; must be closed
    getTransaction().begin() / commit() / rollback()Resource-local transaction, needed for insert, update, delete
    em.persist(obj)Saves a new entity (INSERT)
    em.find(Class, id)Reads by primary key; null if not found
    em.merge(obj)Copies a detached object into the database
    em.remove(obj)Deletes the entity
    em.createQuery(jpql, Class)JPQL query; getResultList() returns a list

    Entity states: New (created with new) → Managed (after persist or find; changes are saved automatically at commit) → Detached (EntityManager closed) → Removed (after remove). JPQL uses class and field names (SELECT p FROM Product p), so it is database independent, unlike SQL.

    JPA versus Hibernate?

    JPA is a specification (interfaces and rules). Hibernate is a product that implements it and adds extra features.

    persist() versus merge()?

    persist is for new entities. merge is for detached entities and updates the existing row.

    What is the first-level cache?

    The EntityManager keeps loaded objects. The same find() twice in one session hits the database once. It is always on.

    Why RESOURCE_LOCAL?

    We manage transactions ourselves with em.getTransaction(). With JTA the server manages them.

    What does hbm2ddl.auto do?

    create drops and creates, update creates or alters if needed, validate only checks, none does nothing. We use update.

    9c. Store and retrieve book details using JPA

    Question. Create a simple JPA application to store and retrieve book details.

    RUNhttp://localhost:8080/ORMLab/BookServlet

    The form stores a book. The list retrieves all books. Click an ID or open BookServlet?id=1 to retrieve one book.

    Output: table of books. ?id=1 prints 1: Java by Author - Rs 450.0 above the table.

    Code explained

    SyntaxMeaning
    storedoPost: new Book → set fields → persist inside a transaction
    retrieve oneem.find(Book.class, id). No transaction needed for reading
    retrieve allJPQL SELECT b FROM Book b
    BookServlet?id=...Link that passes the id in the query string
    Entity ruleNeeds @Entity, @Id and a public no-argument constructor (Java gives one automatically if you write none)
    What is JPQL?

    Java Persistence Query Language. It queries entity classes and their fields (FROM Book b), not tables and columns.

    Why must persist be inside a transaction?

    Writes are only saved on commit. Without begin and commit you get TransactionRequiredException.
